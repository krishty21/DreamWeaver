     3→## Project Overview
     4→DreamWeaver: a dream capture → AI (Gemini via z-ai-web-dev-sdk) structured analysis → longitudinal pattern memory → interactive Subconscious Arcade (RE-ENTER DREAM with REPLAY/REWRITE/CONFRONT) product.

     6→Adapted from the master build instruction (which targeted Google Cloud Run + Firebase + Firestore + Secret Manager) to this sandbox stack:
     7→- Firebase Auth → NextAuth.js v4 Credentials provider (bcrypt-hashed passwords in Prisma)

     9→- Gemini API → z-ai-web-dev-sdk LLM skill (backend only), structured JSON output + zod validation
    10→- Secret Manager → server-only SDK credentials (never shipped to client)

   200→## Goals / completed modifications / verification results
   201→1. BUG FIX (latent, mobile): horizontal overflow on dream-detail (scrollWidth 723 vs 390) and patterns (650 vs 390).
   202→   - Root causes (two compounding):

   401→   - New `src/lib/tts-cache.ts`: in-memory LRU cache keyed by `tts:<fnv1a(spokenText)>::<voice>::<speed.toFixed(2)>`. The spoken text (title + summary + raw) is hashed with FNV-1a (32-bit, dependency-free) so a re-reflect (which replaces the title + summary) correctly invalidates the cache — the key detects the text changed and a fresh synthesis is produced.
